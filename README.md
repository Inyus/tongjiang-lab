# Per què? · Lliçons 3D interactives de ciència

Traducció al català de **[Tongjiang Lab (铜匠实验室)](https://github.com/smithjohn78390/tongjiang-lab)**: 54 lliçons 3D interactives de física, química, biologia i geografia de batxillerat. Cada lliçó és **un únic fitxer HTML** que funciona sense connexió, en un projector o en una pissarra digital. Comença amb una pregunta i et guia pas a pas.

Web: **https://perque.noeba.cat**

## Com s'utilitza

- **En línia**: obre qualsevol lliçó des del portal.
- **Pantalla**: per fer els experiments, fes servir un ordinador amb una finestra d'almenys 1024 px d'amplada. En mòbils i pantalles estretes les lliçons s'obren, però l'experiència no està adaptada (és una limitació de l'aplicació original).
- **Sense connexió**: descarrega un fitxer de `courses/` i obre'l amb Chrome o Edge.
- **Dades**: [`catalog.json`](catalog.json) té totes les lliçons amb la seva ubicació al llibre de text i els passos.
